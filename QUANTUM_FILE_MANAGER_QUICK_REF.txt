WHAT IS QUANTUM FILE MANAGER?
=============================

Integrates quantum-inspired algorithms into classical file management:
  - Grover's Algorithm: Fast O(sqrt(N)) search instead of O(N)
  - Quantum Annealing: Optimal file organization
  - Quantum Hashing: Fast deduplication
  - Semantic Search: Smart file discovery

OPTIMIZATION METHODS
====================

access_speed:
  - Sort by priority (most accessed first)
  - Best for: Frequently accessed files
  - Benefit: Faster access, better cache hits

storage_efficiency:
  - Sort by entropy (compression potential)
  - Best for: Storage optimization
  - Benefit: Identify compressible files

listing_speed:
  - Sort by size (small files first)
  - Best for: Directory listing performance
  - Benefit: Faster enumeration

TECHNICAL DETAILS
=================

Quantum File State:
  - path: Full file path
  - name: Filename
  - size: File size in bytes
  - entropy: Shannon entropy (0-1)
  - priority: Quantum priority score
  - state: "superposition", "collapsed", "optimized"

File Entropy:
  - Measures randomness of file content
  - 0 = Highly compressible
  - 1 = Maximum entropy
  - Used for optimization decisions

Quantum Priority:
  - size_factor: 30% weight
  - entropy: 30% weight
  - recency: 40% weight
  - Combined via quantum amplitude
  - Higher = better access candidate

TROUBLESHOOTING
===============

Nothing found in search:
  - Check pattern syntax
  - Try wildcards: *.extension
  - Try semantic search instead

Slow deduplication:
  - Use on smaller directories
  - Run during off-peak hours
  - Check disk I/O

API endpoint error:
  - Verify server running (port 5001)
  - Check endpoint path: /api/quantum/...
  - Ensure Flask installed: pip install flask

Performance not improving:
  - Try different optimization method
  - Clear cache: restart server
  - Check file system health
