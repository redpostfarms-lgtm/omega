API ENDPOINTS (For Developers)
===============================

Health Check:
  http://localhost:5001/api/health

Browse Directory:
  http://localhost:5001/api/browse?directory=.&sort_by=name

Search Files:
  http://localhost:5001/api/search?pattern=*.py

Get File Info:
  http://localhost:5001/api/file-info?path=filename.txt

Directory Statistics:
  http://localhost:5001/api/stats?directory=.

Recent Files:
  http://localhost:5001/api/recent?limit=10


TROUBLESHOOTING
================

"Address already in use" error:
  - Close other instances
  - Or change port: python gatekeeper_file_manager_web.py --port 5002

UI shows blank page:
  - Wait 5 seconds for page to load
  - Refresh browser (F5)
  - Check console for errors (F12)

Cannot connect to server:
  - Verify batch/script is running
  - Check Python window for errors
  - Ensure port 5001 is available

Files show but won't open:
  - Double-click directories only
  - Use system explorer to open files
  - Check file permissions
