DEPLOYMENT INSTRUCTIONS
========================

Step 1: Copy Files
  Copy all files to h:\The Gatekeeper directory

Step 2: Verify Dependencies
  pip install flask flask-cors

Step 3: Start Server
  Option A - Batch:
    double-click LAUNCH_FILE_MANAGER.bat
  
  Option B - PowerShell:
    powershell -ExecutionPolicy Bypass -File Launch-FileManager.ps1
  
  Option C - Direct:
    python gatekeeper_file_manager_web.py

Step 4: Access UI
  - Standalone: Open file_manager_ui.html in browser
  - Server: Navigate to http://localhost:5001
  - API: Use http://localhost:5001/api endpoints

Step 5: Integration (Optional)
  - Add import to gatekeeper_integration_module.py
  - Add route to omega_control_panel_web.py
  - Add to admin startup scripts


USAGE EXAMPLES
==============

Python API:
  from gatekeeper_file_manager import FileManager
  
  fm = FileManager(root_path="h:\\The Gatekeeper")
  files = fm.list_directory(".")
  results = fm.search("*.py")
  info = fm.get_file_info("file.txt")

REST API:
  curl http://localhost:5001/api/browse?directory=.
  curl http://localhost:5001/api/search?pattern=*.py
  curl http://localhost:5001/api/stats?directory=.
