TROUBLESHOOTING GUIDE
════════════════════════════════════════════════════════════════════════════

PROBLEM: "Access Denied" Error
─────────────────────────────
SOLUTION 1: Use batch launcher
  run_gatekeeper_admin.bat

SOLUTION 2: Use PowerShell launcher
  .\run_gatekeeper_admin.ps1

SOLUTION 3: Manual admin elevation
  Right-click PowerShell > Run as Administrator


PROBLEM: Cannot Write Log Files
─────────────────────────────────
SOLUTION 1: Verify logs directory
  python gatekeeper_admin_helper.py

SOLUTION 2: Fix permissions
  icacls logs /grant "%USERNAME%":F

SOLUTION 3: Run with admin
  run_gatekeeper_admin.bat


PROBLEM: Config Not Saving
──────────────────────────
SOLUTION 1: Check directory permissions
  icacls "." /grant "%USERNAME%":F

SOLUTION 2: Run admin helper
  python gatekeeper_admin_helper.py

SOLUTION 3: Admin launch
  .\run_gatekeeper_admin.ps1


PROBLEM: Still Getting Permission Errors
──────────────────────────────────────────
SOLUTION: Full recursive permission grant
  icacls "h:\The Gatekeeper" /grant "%USERNAME%":F /T
