## 🎯 WHAT YOU'RE INSTALLING

```
THREE COMPONENTS:

1. OpenRGB Application
   ↓
   Allows software to control RGB LED hardware
   
2. FFmpeg Library
   ↓
   Enables audio encoding for TTS output
   
3. CUDA Toolkit (Optional)
   ↓
   GPU acceleration (4-10x faster)
```

---

## 🚀 THE STEPS

### STEP 1️⃣: OPENRGB (5 minutes)

```
1. Go to: https://openrgb.org/download
2. Download: OpenRGB Windows Release
3. Extract ZIP file
4. Run: OpenRGB.exe
5. Keep it running in background ← IMPORTANT!
```

**Test:**
```bash
# Should show OpenRGB is loaded
python -c "import openrgb_python; print('✓ OK')"
```

---

### STEP 2️⃣: FFMPEG (10 minutes)

```
1. Go to: https://ffmpeg.org/download.html
2. Download: FFmpeg full build (Windows)
3. Extract to: C:\ffmpeg
4. Add to PATH:
   Win + X → "Environment Variables"
   → System variables → Path → Edit
   → New → C:\ffmpeg\bin → OK
5. Restart terminal
```

**Test:**
```bash
ffmpeg -version
# Should show version info
```

---

### STEP 3️⃣: CUDA (Optional - GPU)

```
ONLY if you have NVIDIA GPU

1. Check: nvidia-smi
   (if not found, skip this step)

2. Go to: https://developer.nvidia.com/cuda-toolkit
3. Download: CUDA 12.1 (Windows)
4. Run installer as Admin
5. Check: CUDA Toolkit + cuDNN
6. Restart computer
7. Run:
   pip uninstall torch -y
   pip install torch --index-url https://download.pytorch.org/whl/cu121
```

**Test:**
```bash
python -c "import torch; print(torch.cuda.is_available())"
# Should show: True
```

---

## 📊 STATUS AFTER INSTALLATION

### ✓ Working:
- RGB hardware responds to color commands
- Audio files generate without errors
- (Optional) GPU acceleration enabled

### ⚠️ Common Issues:

**"FFmpeg not found"**
- Restart terminal
- Check PATH was added correctly
- Restart computer if needed

**"RGB still Simulated"**
- Is OpenRGB.exe running?
- Check if devices show in OpenRGB window
- Check USB cable connections

**"CUDA still False"**
- Do you have NVIDIA GPU? (nvidia-smi)
- Did you restart after CUDA install?
- Reinstall PyTorch after CUDA
