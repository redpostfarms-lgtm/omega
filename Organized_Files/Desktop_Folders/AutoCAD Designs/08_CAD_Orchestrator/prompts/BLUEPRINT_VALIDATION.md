# Prompt Template: Blueprint Validation & Feasibility Check

## Usage

Before generating build code, validate the Blueprint for feasibility and design rules.

---

## Prompt Structure

```text
TASK: Validate Blueprint for Feasibility

BLUEPRINT FILE:
{blueprint_file_path}

VALIDATION CHECKS:

1) Hole Placement Validation
   - Verify bolt holes don't intersect walls
   - Check hole diameter vs wall thickness
   - Ensure holes aren't too close to edges (minimum: 2x hole diameter from edge)
   - Verify hole depth doesn't exceed part thickness

2) Wall Thickness Validation
   - Check minimum wall thickness (recommended: 0.1in / 2.5mm minimum)
   - Verify lid thickness doesn't conflict with cavity
   - Ensure wall thickness is manufacturable

3) Dimension Validation
   - Verify all dimensions are positive
   - Check dimension consistency (inner vs outer)
   - Ensure features fit within part bounds

4) Layer Compliance
   - Verify all layer names exist in LAYER_STANDARD.json
   - Check layer assignments are appropriate

5) Export Feasibility
   - Verify 3D geometry can export to STEP
   - Check if 2D views are needed for DXF
   - Ensure export settings match geometry type

OUTPUT:
1) Create validation report: 08_CAD_Orchestrator\logs\{name}_validation.md
2) List any warnings or errors
3) If validation passes, proceed to build code generation
4) If validation fails, suggest fixes to Blueprint
```text

---

## Validation Rules

### Minimum Clearances
- **Hole to edge:** 2 × hole_diameter minimum
- **Hole to wall:** 1 × hole_diameter minimum
- **Wall thickness:** 0.1in (2.5mm) minimum for manufacturability

### Geometry Checks
- **Hole depth:** Must not exceed part thickness
- **Inner cavity:** Must be smaller than outer dimensions
- **Lid fit:** Lid dimensions must match or exceed opening

### Export Checks
- **STEP:** Requires solid 3D geometry
- **DXF:** Requires 2D projection (may need separate 2D views)

---
