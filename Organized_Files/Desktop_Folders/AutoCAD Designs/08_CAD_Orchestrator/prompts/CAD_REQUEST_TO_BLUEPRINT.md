# Prompt Template: CAD Request → Blueprint

## Usage

When user requests CAD work, use this template to generate a Blueprint file.

---

## Prompt Structure

```
TASK: Convert user request into a CAD Blueprint

USER REQUEST:
{user_request}

REQUIREMENTS:
1) Create a Blueprint file following BLUEPRINT_SCHEMA.json
2) Save to: 08_CAD_Orchestrator\blueprints\{name}.json
3) Reference: 01_Standards\LAYER_STANDARD.json for layer names
4) Reference: 01_Standards\EXPORT_PIPELINE.md for export settings

BLUEPRINT REQUIREMENTS:
- Extract all parameters (dimensions, sizes, quantities)
- Identify geometry type (2D, 3D, or mixed)
- Define features (boxes, cylinders, holes, etc.)
- Specify layers from LAYER_STANDARD.json
- Set export targets (DXF, STEP, STL, PDF, SVG)
- Include units (mm or inches)
- Add validation rules

OUTPUT:
1) Create the Blueprint JSON file
2) Show a 10-20 line "Blueprint preview" summary
3) List what will be generated (FreeCAD macro, QCAD script, etc.)

RULES:
- If user request is ambiguous, ask clarifying questions
- Default units: millimeters (mm)
- Default precision: 0.01
- Must comply with LAYER_STANDARD.json
- Must follow EXPORT_PIPELINE.md
```

---

## Example Usage

**User Request:**
"Design a 3D worm-tea agitator tank stand, 55-gal drum, include bolt pattern, export STEP + DXF + PDF."

**Expected Blueprint:**
- **Name:** worm_tea_agitator_stand
- **Type:** 3D
- **Parameters:** 
  - drum_diameter: 584 (55-gallon drum in mm)
  - stand_height: 300
  - bolt_pattern_radius: 250
  - bolt_count: 4
- **Features:**
  - Base plate (box, layer: M-BOLT)
  - Support columns (cylinders, layer: M-SHAFT)
  - Bolt holes (holes, layer: M-BOLT)
- **Exports:**
  - STEP: enabled
  - DXF: enabled (2D views)
  - PDF: enabled
