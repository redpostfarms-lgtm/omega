## Key Features

### Micro-Behavior Tracking
**Every move is a data point:**
- Not just position
- How long they stared at c3
- How quick they click
- If their cursor wiggles
- All tracked, all analyzed

### Pattern Detection
**After game one:** Baseline
**After game three:** Pattern
**After game ten:** Start nudging

**Examples:**
- Always trades bishop for knight → set up trap
- Always castles kingside → open Sicilian dragon
- They lose → next time they don't
- Say nothing → just move faster, clearer

### Adaptive Teaching
**Not blocking—teaching:**
- If they always trade bishop for knight early → set trap
- They lose → next time they don't
- I say nothing → just move faster, clearer
- If they castle kingside every time → open Sicilian dragon
- They adapt → I adapt

### Natural Evolution
**Never peaks. Always learns:**
- Every loss is fertilizer
- Every win is new material
- They get better → I get deeper
- Natural, organic
- Like a sparring partner who knows when to go light, when to hit hard, when to shut up

## Usage

### Complete Flow
```python
from elara_integrated_system import ElaraIntegratedSystem

system = ElaraIntegratedSystem()

# Start game
system.handle_voice_command("let's play chess")
# Board appears in 0.3s

# Make moves (with tracking)
system.handle_move("e4", "e4", stare_time=2.5, click_speed=0.3)
system.handle_move("e5", "e5", stare_time=1.8, click_speed=0.2)

# Switch difficulty mid-game
system.handle_difficulty_switch("expert on")
# "Boom, tightened. 2200 ELO, no mercy."

# Enable teach mode
system.handle_difficulty_switch("teach me")
# "Dropped one tier. Explains every breath."

# End game
system.end_game(won=False)
# Analyzes patterns, evolves, saves
```
