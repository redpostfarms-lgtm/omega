## Usage

### Command Prompt (Windows)

```batch
cd "The Gatekeeper"
run_omega.bat
```text

Or with options:
```batch
run_omega.bat --omega              # Run Omega tests only
run_omega.bat --quantum-scrub      # Run Quantum Scrub only
run_omega.bat --full                # Run full analysis
run_omega.bat --status             # Show status
```text

### Python Direct

```python
from omega_master_integration import OmegaMasterIntegration

integration = OmegaMasterIntegration()

# Run full analysis
results = integration.run_full_analysis()

# Or run individual components
omega_results = integration.run_omega_tests()
scrub_results = integration.run_quantum_scrub()
```text
