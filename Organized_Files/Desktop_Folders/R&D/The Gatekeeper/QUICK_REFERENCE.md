# Gatekeeper Quick Reference Card

## Voice Commands

### Learning Commands
- **"Hey, Gatekeeper, go to college on [topic]"** - Learn everything about a topic
- **"Hey, Gatekeeper, go to school on [topic]"** - Same as above

### Status Commands
- **"Hey, Gatekeeper, status"** - System status check
- **"Hey, Gatekeeper, charge level?"** - Battery report

### Grant Commands
- **"Hey, Gatekeeper, new REAP grant 15k"** - Create USDA grant

### Weather Commands
- **"Hey, Gatekeeper, sun tomorrow?"** - Solar forecast

### App Commands
- **"Hey, Gatekeeper, open Word"** - Launch application
- **"Hey, Gatekeeper, open Excel"** - Launch application
- **"Hey, Gatekeeper, open Photoshop"** - Launch application

### Emergency Commands
- **"Gatekeeper, scorched earth"** (say 3x fast) - Emergency shutdown

### Personality Commands
- **"Gatekeeper, why so quiet?"** - One-time joke response
