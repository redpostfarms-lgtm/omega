## Quick Start

### **1. Install Dependencies (If Not Done)**
```bash
cd "The Gatekeeper"
pip install -r requirements.txt
```

### **2. Run Build System**
```bash
python build_system.py
```

### **3. Start Building**

**Voice Command:**
```
"Hey, Gatekeeper, write a quantum-safe BMS in Rust"
```

**Direct Command:**
```bash
python gatekeeper_fusion.py "write a quantum-safe BMS in Rust"
```

## Build Workflow

1. **Define the project** (voice or command line)
2. **Fusion system runs** (4 models in parallel)
3. **Output synthesized** (all models contribute)
4. **Code saved** to `Archived/fusion_outputs/`
5. **Review and refine** (iterate as needed)

---

## Output Location

All fusion outputs saved to:
```
D:\RPF_BRAIN\Archived\fusion_outputs\fusion_YYYYMMDD_HHMMSS.md
```
