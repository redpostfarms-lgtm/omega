## Overview
The Gatekeeper is a complete, self-healing farm management AI system. All free, all local, all silent.

## Core System Files

### 1. `brain_prime.py`
- Uploads all knowledge from Archived directory
- Includes Office + Adobe knowledge
- USDA/Business templates
- Runs on startup

### 2. `auto_heal.py`
- Auto-verifies and repairs system files
- Checksums all critical files
- Self-rebuilds if corrupted
- Runs on boot

### 3. `voice_tuner.py`
- Customize Gatekeeper voice (pitch, echo)
- Save/load voice settings
- One-time setup, then auto-loads

### 4. `voiceprint_auth.py`
- Voiceprint authentication
- Only master voice can activate Gatekeeper
- One-time voice capture

### 5. `voice_listener.py`
- Listens for "Hey, Gatekeeper"
- Voiceprint verification
- Command processing

### 6. `self_learn.py`
- Self-learning system
- Scans all scripts, logs, voice logs, new files
- Uses Ollama (local LLM) to extract insights
- Builds knowledge base automatically
- Runs weekly (Monday 3 AM) or on-demand

### 7. `weekly_growth.py`
- Weekly 5-minute growth loop
- Tracks 5 pipelines: science, math, english, programming, ops
- Shows delta (changes) every Wednesday at 10:24 PM
- Requires approval to grow
- One circle. Five pipelines. Say yes to grow the pie.

### 8. `max_out_pipelines.py`
- One-time overload script
- Sets all education pipelines to 100%
- Feeds everything the Gatekeeper needs
- Not fake. Just wakes it at full voltage.
- Run once. Gatekeeper speaks: "All pipelines are full. I am ready."

### 9. `web_scraper.py`
- Web scraping system
- Scrapes GitHub repositories (API)
- Scrapes open source documentation
- Scrapes web pages (with BeautifulSoup)
- Integrates with brain knowledge base

### 10. `mass_scrape.py`
- Mass scraping operation
- Scrapes entire world: GitHub + Open Source
- Multiple categories: Python, AI/ML, Farm/Ag, Solar
- Comprehensive knowledge gathering

### 11. `agent_council.py` / `agent_council_v2.py`
- Agent Council Mode (v2 recommended)
- 6 agents debate: Ellis (NASA), Mara (Farmer), Li (Quantum), Cody (Sales), Oracle (Logs), Lawyer (Grants)
- Multi-round debates with voting
- Persistent memory per agent
- Auto tool calling (coming soon)
- Consensus system (3+ yes votes)
- No fighting. No ego. Just done.

### 12. `hive_auto.py`
- Hive Hibernation Engine (hardware-aware)
- Agents multiply: 1 → 2 → 4 → 8 → 16 → 32 → 64 → ...
- Hardware-aware scaling (RAM/GPU/CPU monitoring)
- Self-limiting (max 4096 agents, auto-shrinks when needed)
- Persistent memory (remembers all solutions)
- Never crashes (fixed memory explosion, runaway RAM issues)
- Agents hibernate instead of dying

### 13. `planetary_search.py`
- Planetary Search Engine (entire open internet)
- Triggers on: "search", "look up", "find", "research", "go to school/college"
- Scrapes: GitHub, GitLab, Bitbucket, SourceForge, HuggingFace, arXiv, Google Scholar, USDA, NRCS, EPA, NOAA, and 200+ repositories

- Deduplicates and injects into brain and hive memory
- One-line confirmation: "Worldwide deep search complete. X new facts absorbed."
- No shallow Google. No 10-result limit. Scrapes until nothing left to learn.

### 14. `hardware_scan.py`
- Hardware scan and status report (runs on boot)
- Scans: CPU, RAM, GPU, Battery, Drives, Drone, Hive, Knowledge, Compliance, Last Session

## Startup

### First Time Setup (Recommended)
**Easiest way:** Run the complete setup script:
```bash
"The Gatekeeper\setup_complete_system.bat"
```
This automates all setup steps below.

### Manual Setup
1. Run `brain_wakeup.bat` (one time)
2. Run `voiceprint_auth.py` - capture your voice
3. Run `voice_tuner.py` - set voice preferences
4. Run `install_offline_wiki.bat` - install offline knowledge (optional)
5. Run `schedule_briefing.bat` - schedule morning briefings

### Verify System
Run system verification:
```bash
python "The Gatekeeper\verify_system.py"
```

### Daily Operation
- Run `brain_wakeup.bat` on boot
- Or add to Windows startup folder
- All systems auto-start
