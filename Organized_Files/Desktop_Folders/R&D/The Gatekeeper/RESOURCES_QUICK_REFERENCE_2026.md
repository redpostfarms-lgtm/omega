## 🔗 Top 20 Resources by Priority

### **Tier 1: Critical (Install First)**

1. **Scrapy** - Production web scraping
   - `pip install scrapy`
   - https://github.com/scrapy/scrapy

2. **Vosk** - Offline speech recognition
   - `pip install vosk`
   - Models: https://alphacephei.com/vosk/models

3. **ChromaDB** - Vector database
   - `pip install chromadb`
   - https://github.com/chroma-core/chroma

4. **llama.cpp** - Local LLM runtime
   - `pip install llama-cpp-python`
   - Models: HuggingFace (Phi-3, Llama-3.2)

### **Tier 2: High Priority**

5. **SpeechBrain** - Voice biometrics
   - `pip install speechbrain`
   - https://github.com/speechbrain/speechbrain

6. **Piper** - Text-to-speech
   - Clone: `git clone https://github.com/rhasspy/piper`
   - https://github.com/rhasspy/piper

7. **Sentence Transformers** - Text embeddings
   - `pip install sentence-transformers`
   - https://github.com/UKPLab/sentence-transformers

8. **CrewAI** - Multi-agent framework
   - `pip install crewai`
   - https://github.com/joaomdmoura/crewAI

9. **LangChain** - Agent orchestration
   - `pip install langchain langchain-community`
   - https://github.com/langchain-ai/langchain

10. **NeuralProphet** - Time series forecasting
    - `pip install neuralprophet`
    - https://github.com/ourownstory/neural_prophet

### **Tier 3: Medium Priority**

11. **Playwright** - JavaScript rendering
    - `pip install playwright && playwright install`
    - https://github.com/microsoft/playwright

12. **FAISS** - Fast similarity search
    - `pip install faiss-cpu` (or `faiss-gpu`)
    - https://github.com/facebookresearch/faiss

13. **ReportLab** - PDF generation
    - `pip install reportlab`
    - https://github.com/MrBitcoin/reportlab

14. **WeasyPrint** - HTML to PDF
    - `pip install weasyprint`
    - https://github.com/Kozea/WeasyPrint

15. **pytest** - Testing framework
    - `pip install pytest pytest-cov`
    - https://github.com/pytest-dev/pytest

### **Tier 4: Agriculture-Specific**

16. **PlantNet API** - Plant identification
    - Free: 500 requests/day
    - https://my.plantnet.org

17. **iNaturalist API** - Plant/animal ID
    - Free: Unlimited (rate limited)
    - https://www.inaturalist.org

18. **NOAA Climate API** - Weather data
    - Free: Unlimited (5 req/sec)
    - https://www.ncdc.noaa.gov/cdo-web/webservices/v2

19. **USDA FoodData API** - Food/nutrient data
    - Free: Unlimited (3600 req/hour)
    - https://fdc.nal.usda.gov/api-guide.html

20. **FarmOS** - Farm management reference
    - Open-source: https://farmos.org
    - https://github.com/farmOS/farmOS
