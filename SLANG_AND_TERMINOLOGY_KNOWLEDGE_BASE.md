## Coding Slang & Terminology

### General Programming Slang

| Term | Meaning | Context | Example Usage |
| ------ | --------- | --------- | --------------- |
| **Bug** | Error or flaw in code | Universal | "There's a bug in the login function" |
| **Debug** | Fix errors in code | Universal | "I need to debug this function" |
| **Hack** | Quick solution, often inelegant | Informal | "This is a hack but it works" |
| **Kludge** | Temporary, messy solution | Informal | "This kludge will do for now" |
| **Refactor** | Restructure code without changing behavior | Professional | "Let's refactor this module" |
| **Ship it** | Deploy/release code | Informal | "Looks good, ship it!" |
| **YOLO merge** | Merge code without thorough review | Humorous/risky | "YOLO merge, let's see what happens" |
| **Spaghetti code** | Unorganized, tangled code | Negative | "This is spaghetti code" |
| **God object** | Object that does too much | Design pattern | "This is a god object, needs splitting" |
| **Tech debt** | Shortcuts that need fixing later | Professional | "We're accumulating tech debt" |
| **Bikeshedding** | Arguing over trivial details | Meeting context | "We're bikeshedding again" |
| **Rubber duck debugging** | Explaining code to inanimate object | Problem-solving | "Let me rubber duck this" |
| **Code smell** | Indication of deeper problem | Code quality | "This has a code smell" |
| **Premature optimization** | Optimizing before it's needed | Performance | "That's premature optimization" |
| **Feature creep** | Uncontrolled feature addition | Project management | "We have feature creep" |
| **Scope creep** | Project scope expanding | Project management | "This is scope creep" |

### Language-Specific Slang

#### Python
- **Pythonic** - Code that follows Python idioms
- **Duck typing** - "If it walks like a duck..."
- **Zen of Python** - Python philosophy
- **PEP** - Python Enhancement Proposal
- **List comprehension** - Concise list creation
- **GIL** - Global Interpreter Lock
- **Pip** - Package installer
- **Virtualenv** - Isolated Python environment
- **Decorator** - Function wrapper
- **Generator** - Lazy iterator
- **Lambda** - Anonymous function
- **Dunder methods** - `__init__`, `__str__`, etc.

#### JavaScript/TypeScript
- **Callback hell** - Nested callbacks
- **Promise chain** - Async promise handling
- **Hoisting** - Variable/function declaration behavior
- **Closure** - Function with preserved scope
- **IIFE** - Immediately Invoked Function Expression
- **Polyfill** - Code that adds missing features
- **Shim** - Compatibility layer
- **Bundler** - Package bundler (webpack, etc.)
- **Transpiler** - Source-to-source compiler
- **JSX** - JavaScript XML syntax
- **Hooks** - React function components
- **Props drilling** - Passing props through many components

#### General CS Terms
- **Stack overflow** - Too much recursion
- **Null pointer** - Uninitialized reference
- **Race condition** - Timing-dependent bug
- **Deadlock** - Circular waiting
- **Memory leak** - Unfreed memory
- **Cache miss** - Data not in cache
- **Big O** - Algorithm complexity
- **Brute force** - Try all possibilities
- **Heuristic** - Rule-of-thumb solution
- **Greedy algorithm** - Local optimal choices

## Contextual Usage Guidelines

### When to Use Slang

1. **Informal Communication**
   - Text messages
   - Social media
   - Casual conversations
   - Friendly emails

2. **Creative Writing**
   - Character dialogue
   - First-person narration
   - Contemporary settings
   - Youth-oriented content

3. **Avoid in Formal Contexts**
   - Academic papers
   - Business communications
   - Legal documents
   - Professional presentations

### Context Awareness

- **Audience**: Know your audience's familiarity
- **Setting**: Match slang to time period/setting
- **Tone**: Slang affects tone (casual vs. formal)
- **Purpose**: Informational vs. entertainment

### Regional Variations

- **American**: Dude, awesome, cool
- **British**: Bloke, brilliant, proper
- **Australian**: Mate, g'day, fair dinkum
- **Canadian**: Eh, toque, double-double
- **Internet**: Universal terms (LOL, OMG, etc.)

### Temporal Evolution

- **Historical accuracy**: Use period-appropriate slang
- **Contemporary relevance**: Current slang changes rapidly
- **Generational differences**: Different age groups use different slang
- **Cultural context**: Slang reflects cultural moments
